floJAY
Combine FlowJo table exports, rebuild panels, subtract baseline, export tidy data. Runs in your browser; nothing is uploaded.

1Load FlowJo exports

Drop one or more .xlsx files exported from FlowJo. Only the Table sheet (or the first sheet) of each file is read. Rows whose name does not match the sample-name pattern (e.g. Mean, SD) are dropped automatically and listed below the table.

2Sample name pattern

Describe how the first column is built. Each {NAME} becomes a column in the output and can be used for baseline subtraction. Spaces around separators are flexible.

3Column sets (panels)

Each set becomes one sheet in the output. Tick the columns you want from the list (it fills from the loaded files), or load a preset. Selections are stored as shorthand (gate/path | Statistic) which you can also edit as text under Advanced: the gate part only needs the end of the gating path, the statistic only its start, * is a wildcard, # starts a comment.
